# Formula KART Driving Challenge (FKDC) 2026 🏎️

**Team:** Parikshit Racing | SAE Club | Motilal Nehru National Institute of Technology (MNNIT)

## 📌 About the Project
This repository contains the official engineering designs, simulation data, and software systems for the MNNIT SAE Club's 2026 FKDC vehicle. It serves as the central version control hub for cross-departmental collaboration between the Mechanical, Analysis, and Electronics & Electrical teams.

## 📂 Repository Structure
* **`/CAD_SolidWorks`**: Contains all 3D part files (`.sldprt`), main assemblies (`.sldasm`), and technical drawings.
* **`/Electronics_and_Code`**: Source code for vehicle control systems, sensor integration, computer vision scripts, and circuit schematics.
* **`/Analysis`**: FEA/CFD simulation reports, mathematical models, and performance data.
* **`/Documentation`**: Bill of Materials (BOM), rulebook references, and design reports.

## 🤝 Contribution Guidelines
To prevent overwritten files and broken assemblies, please follow this workflow:
1. **Never push directly to the `main` branch.**
2. Create a new branch for your department's current task (e.g., `chassis-cad-update` or `sensor-calibration-code`).
3. Upload your changes to your branch and open a **Pull Request**.
4. **SolidWorks Notice:** Always ensure your part files are correctly linked to the main assembly before uploading. Pack and Go is recommended.
